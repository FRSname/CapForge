## Goal (exit test from §7)

Run the publish skill on a conference recording, paste the package into YouTube Studio with **zero manual fixes**. Text comes from the LLM; CapForge supplies timing, structure, validation, storage and review.

## Contracts

### Backend (`backend/library/`)

- **`brief.py`** — `Brief` (Pydantic, `extra="forbid"`): `channel: str = ""`, `audience: str = ""`, `voice: str = ""`, `language: str = ""` (empty = transcript language), `footer: str = ""`, `recorded_at_line: str = ""`, `speaker_block: str = ""`, `default_hashtags: list[str] = []`, `link_rows: list[Link] = []`, `house_rules: HouseRules` with `no_em_dashes: bool = False`, `description_chars: tuple[int, int] | None = None` (e.g. `(1800, 2200)`), `keywords_terms: tuple[int, int] | None = None` (e.g. `(12, 20)`), `hook_first_150: bool = True`. `BriefPatch` = every field optional. Stored at `library_root()/brief.json` via `write_json_atomic`; `load_brief()` returns defaults when the file is missing; `save_brief(patch) -> Brief` merges top-level fields.
- **`validate.py`** — `validate_fields(fields: dict, *, duration: float | None, brief: Brief | None) -> list[Violation]` where `Violation{field, rule, message, severity: 'hard' | 'style'}`. Hard rules, always: `TITLE_MAX_CHARS = 100` (title and each `title_options[]`), `DESCRIPTION_MAX_BYTES = 5000` (UTF-8), `TAGS_MAX_CHARS = 500` over `", ".join(tags)`, `NO_ANGLE_BRACKETS` in title / description / tags, chapters: first `start_s == 0`, at least `CHAPTERS_MIN = 3` when any are present, strictly ascending, `CHAPTER_MIN_GAP_S = 10`, all `< duration` when a duration is known. Style rules, only when the brief asks: `no_em_dashes` (em/en dash outside a digit–digit range), `description_chars` window, `keywords_terms` count, `hook_first_150` (the first 150 characters of the description contain no newline and end inside a sentence, i.e. the hook is not cut mid-word is NOT checked — keep it to "non-empty and no newline"). Pure module, fixture-tested. `validate_record(record, transcript_duration, brief)` = the same over the stored dossier.
- **Routes** (all under the injected guard; `/brief` and `/validate` registered before `/{video_id}`): `GET /api/library/brief` → the brief; `PATCH /api/library/brief` body `BriefPatch` → the merged brief (no `If-Match` — one small file); `POST /api/library/validate` body `{fields: dict, duration?: float, video_id?: str}` (with `video_id`, missing `fields`/`duration` are read from the record) → `{violations}`; `GET /api/library/{id}/package?platform=youtube` → `{platform, text, violations}` (the package is rendered even with violations; they ride along); `PATCH /api/library/{id}` now runs the **hard** rules on the merged authored fields and answers `422 {"detail": "...", "violations": [...]}` before writing.
- **`package.py`** — `render_youtube_package(record, brief, *, duration, source_name) -> str` reproducing the skill's layout exactly (TITLE OPTIONS numbered; the `=====` rules; DESCRIPTION with the recorded-at line, WHAT YOU'LL LEARN from `highlights[].text`, CHAPTERS as `MM:SS`/`H:MM:SS` + title, LINKS from `links` then brief `link_rows`, speaker block from `speakers` through the brief template, footer, hashtags with the brief defaults first; TAGS one line; SHORT DESCRIPTION; SHORTS with caption + `Full video:` + `#Shorts` + CLIP CANDIDATES from `shorts.clip_suggestions`; THUMBNAIL IDEAS from `thumbnail.ideas`; NOTES with source/duration, description chars+bytes, caption chars, chapter count/min gap, open placeholders — `[SPEAKER NAME]` when a diarized speaker has no name, `[FULL VIDEO URL]` when `publish.youtube.url` is empty). Sections whose data is empty are dropped the way the skill drops empty channel notes. `format_timestamp(seconds)` lives here and is what the renderer's `lib/youtubeRules.ts` twin is pinned against by a shared JSON fixture `backend/tests/fixtures/timestamp_cases.json` (the RSVP precedent).
- **Session proxy + change push**: `build_router(actor_dep, *, live_session=None, on_record_changed=None)`. `live_session()` returns `(active_video_id, current_result)` read from `current_ui_state["activeVideoId"]` and `current_result` in `main.py`; the transcript route returns `{rev, source: "session", transcript}` when the id matches and a result is loaded. `on_record_changed(video_id, rev, by)` is awaited after every successful `PATCH`, promote, renders append, import and `PUT …/project`; `main.py` passes a lambda broadcasting `{"type": "record_updated", "video_id", "rev", "by"}` over `/ws/progress`. `main.py` growth ≤ 15 lines.

## Deviations from the plan above (all deliberate)

- `router_derived.py` (moments + transcript with the session proxy) split out of `router.py` for the size ceiling; `router_publish.py` holds brief/validate/package.
- The chosen `title` leads TITLE OPTIONS (deduped) so a record with a title and no options still yields a pasteable package.
- Style rules stay quiet on an empty field (a blank draft is "not written yet"); hard rules are unconditional. `no_em_dashes` scans title, description and short_description only.
- PATCH ordering is 404 → 422 → 409; `validate_fields` raises on a non-authored key (mapped to 422) rather than filtering silently.
- `on_record_changed` is not announced for a no-op patch; PUT project always announces with `by: "user"`. The autosave `PUT …/project` runs its file I/O in a threadpool so `/ws/progress` is not blocked by a multi-MB snapshot every 2 s (added during review).
- A corrupt `brief.json` answers 500 with the parse message and is left intact — never a silent reset.
- MCP: `validate_video`'s `ok` means "no hard finding"; an unknown severity lands in an `other` bucket rather than vanishing; `get_upload_package` also echoes `platform`. `test_bundled_skills.py` now discovers tools from the `TOOLS` tuples of `library.py`/`publish.py`/`tracks.py`, not only `@mcp.tool()` decorators; the skill's field map sits in fenced blocks so the drift regex does not read field names as tool names.
- Renderer: `usePublishRecord` (373) is split with pure `lib/publishDrafts.ts`, `lib/publishChapters.ts`, `lib/publishTypes.ts` and `hooks/usePublishWriter.ts`; the five agent handlers moved verbatim from App into `hooks/useAgentBridge.ts` and both asides into `components/publish/PublishAside.tsx` to pay for the workspace; `chapterSuggestions` prepends an `Intro` chapter at 00:00 when nothing covers it (otherwise every suggestion is refused on the first-chapter rule); `pendingSeek` is cleared by the playhead callback after `SEEK_SETTLE_S` so the same chapter can be clicked twice; `onRecordUpdated` is a subscriber set on the API singleton; `buildExportParams` moved to `lib/exportParams.ts`.
